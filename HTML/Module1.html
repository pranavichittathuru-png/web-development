Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages. HTML helps us organize headings, paragraphs, images, links, tables, audio and video on a webpage. It uses tags and elements to structure the content of a webpage.

Structure of a Web Page

A basic HTML webpage is structured using different HTML elements. The main sections are the head and body. The head contains information about the webpage, while the body contains the visible content displayed in the browser.

  • <html> - Root element of the webpage
  • <head> - Contains webpage information and styles
  • <title> - Defines the browser tab title
  • <body> - Contains the visible webpage content

Basic HTML Tags

HTML provides different tags to structure and format the content of a webpage.

  • <h1> to <h6> - Headings
  • <p> - Paragraph
  • <br> - Line Break
  • <hr> - Horizontal Line
  • <b> - Bold Text
  • <i> - Italic Text
  • <u> - Underlined Text
  • <mark> - Highlighted Text

HTML Elements

HTML elements are the basic building blocks of a webpage. An element usually consists of a start tag, content and an end tag. Some elements, such as br, hr, img and input, are empty elements and do not require a closing tag.

HTML Headings

HTML provides six levels of headings, from h1 to h6. They are used to organize and structure the content of a webpage. The h1 heading is the most important, while h6 is the least prominent.

HTM-L Paragraphs

The paragraph tag is used to define paragraphs in an HTML webpage. It helps organize and display text in a clear and readable format. Each paragraph starts on a new line.

HTML Hyperlinks

HTML hyperlinks are used to connect one web page to another web page,website,file,or a specific section of the same web page.

Hyper links are are created using the <a>(anchor) tag in HTML.

Syntax of HTML Hyperlink

The basic syntax of an HTML hyperlink is:

<a href="URL">Link Text</a>

Example of HTML Hyperlink

Example: <a href="https://www.google.com">Visit Google</a>

In this example, the href attribute specifies the destination of the link, and "Visit Google" is the clickable text.

Types of Hyperlinks

1. External link - A link that connects to another website.

2. Internal Link - A link that connects to another page within the same website.

3. Email Link - A link that opens an email application to send an email.

4. Bookmark link - A link that moves to a specific section of the same web page.

Important Attributes of Hyperlinks

href - Specifies the destination URL of the hyperlink.

target - Specifies where the linked page should open.

title - Provides additional information about the hyperlink.

HTML tables are used to organize and display data in rows and columns on a web page.

An HTML table is created using the <table> tag. The <tr> tag is used to define a table row, the <th> tag is used to define a table heading, and the <td> tag is used to define table data.

HTML Images

HTML images are used to display pictures on a web page. Images can make a web page more attractive and informative.

The <img> tag is used to add an image to an HTML page. The <img> tag does not require a closing tag.

Syntax of HTML Image

<img src="image.jpg" alt="Description of image">

Example of HTML Image

<img src="flower.jpg" alt="Beautiful Flower">

The src attribute specifies the path or location of the image, while the alt attribute provides alternative text if the image cannot be displayed.

HTML Iframe

An HTML iframe is used to embed another web page or external content inside the current web page.

The <iframe> tag is used to create an iframe. It can be used to display web pages, maps, videos, and other embedded content.

Syntax of HTML Iframe

<iframe src="URL"></iframe>

Example of HTML Iframe

<iframe src="https://www.example.com" width="600" height="400"></iframe>

The src attribute specifies the URL of the content to be displayed inside the iframe. The width and height attributes specify the size of the iframe.

Block and Inline Elements in HTML

HTML elements are mainly divided into two types: block-level elements and inline elements.

Block Elements

Block elements start on a new line and usually take up the full available width of the page.

Examples of block elements are <h1>, <p>, <div>, <ul>, and <table>.

Inline Elements

Inline elements do not start on a new line and take up only the space required by their content.

Examples of inline elements are <a>, <span>, <strong>, <em>, and <img>.

Introduction to HTML5

HTML5 is the latest major version of HTML used to create and structure modern web pages and web applications.

HTML5 provides new elements and features for multimedia, forms, graphics, and better web page structure.

Basic Tags of HTML5

HTML5 provides several useful tags such as <header>, <nav>, <section>, <article>, <aside>, <footer>, <audio>, <video>, and <canvas>.

These tags help create a well-structured and meaningful web page.

Structure of HTML5

The basic structure of an HTML5 document contains the <!DOCTYPE html> declaration, followed by the <html>, <head>, and <body> elements.

Example: <!DOCTYPE html> <html> <head> <title>My Web Page</title> </head> <body> <h1>Welcome</h1> </body> </html>

HTML5 Forms and Attributes

HTML5 forms are used to collect information from users, such as names, email addresses, passwords, and other details.

The <form> tag is used to create a form. Common form attributes include action, method, name, and autocomplete.

Example: <form action="/submit" method="post"></form>

HTML5 Input Types and Attributes

HTML5 provides different input types such as text, password, email, number, date, radio, checkbox, file, and submit.

Common input attributes include placeholder, required, value, name, id, and disabled.

Example: <input type="email" placeholder="Enter your email" required>

HTML5 Multimedia Support

HTML5 provides built-in support for multimedia content such as audio and video without requiring additional plugins.

HTML5 Audio

The <audio> tag is used to add audio files to a web page.

Example: <audio controls><source src="music.mp3" type="audio/mpeg"></audio>

HTML5 Video

The <video> tag is used to add video files to a web page.

Example: <video controls><source src="video.mp4" type="video/mp4"></video>

Audio and Video Controls

The controls attribute adds playback controls such as play, pause, volume, and progress controls for audio and video.

Tools for Web Designing

Web designing tools are software applications used to create, edit, and test web pages and websites.

Some commonly used web designing tools are Visual Studio Code, Sublime Text, Notepad++, Adobe Dreamweaver, and browser developer tools.

Conclusion

HTML5 provides useful features for creating modern web pages, including semantic elements, forms, input types, multimedia support, and better page structure.
